# Security Policy

God Mode is an orchestration and execution skill for Claude Code and coding agents. It executes shell commands, runs acceptance tests, invokes subagents, and writes state ledgers to `.godmode/`.

## Reporting a Vulnerability

If you discover a security vulnerability—such as an unsafe command execution pattern, credential leakage through hooks, or arbitrary script injection—please **do not open a public issue**.

Instead, email **khaiwalsanyam07@gmail.com** with:
- Description of the vulnerability
- Minimal reproduction steps or code snippet
- Potential impact

You will receive an initial response within 48 hours, followed by a status update once a fix is developed and verified.
